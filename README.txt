# Project NOVA 2.0 — Interactive Website Demo

## Open it
1. Extract the ZIP (if using the ZIP).
2. Open `index.html` in a modern browser.
3. No Node.js install or API key is needed for this demo.

## Features that work in this demo
- Responsive dashboard and navigation
- Study task list with checkboxes and delete; stored in localStorage
- Notes Vault with create/delete and JSON export; stored in localStorage
- Focus timer with 25-minute study, 5-minute short break, 15-minute long break, pause/resume/reset
- Interactive sample outputs for Study Assistant, Creative Studio and Innovation Lab

## Simulated or future features
- AI tools return local sample templates; they do not call a real AI model
- Image Prompt Studio creates text prompts only; it does not generate images
- Quiz Center, Knowledge Booster, and Code Generator are represented in the dashboard but are not full working modules
- No user accounts, cloud sync, database, or Android package

This demo is for project presentation and interaction testing, not a production service.
